# MyShows API Automation Tests

Проект автоматизации тестирования API для сервиса рейтинга сериалов.\
В рамках проекта реализовано покрытие позитивными и негативными тест-кейсами эндпоинтов получения данных,\
валидация ответов по JSON-схемам, работа с тестовой базой данных PostgreSQL на уровне фикстур, а также проверка структуры данных.

## Стек

* **Язык программирования:** Python 3.14+
* **Тестовый фреймворк:** Pytest
* **HTTP-клиент:** Requests (с сессионным управлением соединениями)
* **Драйвер БД:** Psycopg 3
* **Валидация данных:** jsonschema, DeepDiff

## Структура проекта

